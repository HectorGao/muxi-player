# 播放内核与资源识别检查（2026-10-22）

范围：现有原生 macOS 客户端的资源详情 → 播放 → 音轨/字幕 → 画质流程。沿用已经选定的界面设计，不另做视觉方案。

## 修改前的直接证据

1. 当前原生窗口中，《银翼杀手2049》停留在 00:00，中央显示 AVPlayer 无法播放；当前截图保存在本机 `.local/engine-audit/01-playback-failure.jpg`。
2. 错误提示建议服务器转码，但此前同一账号返回的策略明确禁止视频/音频转码及转封装。这个建议无法帮助该账号恢复播放。
3. 失败后播放计划被清空，字幕与音轨菜单失效；用户看不到片源容器、编码、可用版本或播放内核。
4. 音轨和字幕选择与画质转换共用 requiresConversion，导致本可本地处理的轨道选择也被服务器权限阻断。

## 本轮实现范围

- 用 IINA 同源的 libmpv 内嵌解码和渲染，保留 SwiftUI 播放界面及 Emby 会话同步。
- 资源详情自动探测版本、视频编码和轨道数量；播放时以指定版本重新协商。
- 音轨/字幕选项依据 mpv 实际识别的 track-list；使用 ff-index 映射 Emby 索引，避免把两种索引混用。
- 外部字幕地址沿用同源令牌和安全 URL 校验；不读取服务器文件路径。
- 画质和码率依旧代表服务器转换上限。账号明确禁止视频转码时禁用这些选项，并解释可选择已有版本。
- 不再展示 AVPlayer 专属画中画按钮。

## 验证记录

1. Core 21 项测试通过；libmpv MKV/MP4 实际解码、轨道切换、外置字幕、480p 转码、暂停位置、坏字幕恢复与 EOF 重播回归通过。
2. 真实影片详情自动识别 4 条音轨、10 条字幕，截图见本机 `.local/engine-audit/02-source-discovery.jpg`。
3. 原生窗口已显示此前失败片源的实际画面，并列出 TrueHD、DTS 和 PGS 字幕；播放时间持续推进，但该高码率源发生网络缓冲，不能声称持续流畅。
4. 用户解锁后启动最终 TLS 校验开启构建，重新登录并打开同一影片，已确认真实 HEVC 画面、进度拖动和国语 DTS 轨道切换。缓冲提示给出实际接收速率与缓存余量，能区分正在等待网络数据与初始化失败；观察到约 9–19 Mbps 的接收速率，低于片源标示的 27.4 Mbps。
5. 最终版约 06:00 的影片画面实际显示简中、英文双语 PGS 字幕，空格暂停后轨道选择和画面保持。本机截图 `.local/engine-audit/03-final-playback-pgs.jpg` 已核对；未将菜单选中状态单独当作字幕渲染证据。
