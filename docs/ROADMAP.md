# muxi 更新路线图

更新于 2026-10-23。产品方向：免费开源的全能视频播放器与私人影视库，面向 macOS 和 Windows。下面是优先级与验收条件，不是已经上线的功能，也不是发布日期承诺。

## 当前基础

macOS Apple Silicon 预览版已提供 Emby / Jellyfin 接入、媒体墙、搜索、规则推荐、收藏、分类筛选、libmpv 播放、轨道选择、续播和独立双全屏。提供版本化 DMG / ZIP、源码与校验值。真实 Jellyfin、Intel 及 Windows 仍需单独验收。

| 优先级 | 待更新内容 | 完成标准 |
| --- | --- | --- |
| P0 · 已定稿 / 部分完成 | C · 石墨薄荷图标 | 已接入无外围留白的 macOS ICNS 与登录页，覆盖 16–1024 px；Windows ICO 随 Windows 原型验收 |

## Windows 交付路径

保留现有 Mac 用户可用版本，先建立 Windows 原生宿主与 libmpv 的最小播放流程。协议数据模型、测试场景和播放行为可复用；UI、渲染、凭据存储与打包需要平台实现。对 Windows UI 技术做小范围验证后再选型，避免提前整体重写。

Windows 首个可下载预览版必须在真实 Windows 设备验证登录、播放、硬件解码、字幕/音轨、退出释放连接、续播、窗口全屏与系统全屏，并提供独立版本包、对应源码、签名状态和 SHA-256；不能用 Mac 测试替代。

## 每次发布

- 代码检查、受影响协议与播放测试、原生界面核对。
- 更新 CHANGELOG 和验证记录，提交并推送 GitHub；使用新 tag，不覆盖旧附件。
- 同时提供安装包、项目源码、依赖源码和校验值，明确已验收的平台范围。
