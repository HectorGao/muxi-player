# muxi 更新路线图

更新于 2026-11-15。产品方向为免费开源的全能视频播放器与私人影视库，逐步覆盖 macOS 和 Windows。

## 产品结构

- 媒体墙统一呈现私人媒体库与公开片源，每个条目保留所属来源。
- 搜索按源并行执行，先展示本机缓存，独立显示各源进度和失败。
- 播放统一使用 libmpv，媒体库协议负责认证与协商，采集接口负责返回线路与分集。
- 元数据按影片标识匹配评分，展示来源和缺失状态，缓存后按需更新。
- 账户、接口配置、收藏和进度分别按所属源保存，密钥放入系统钥匙串。

## 当前基础

macOS Apple Silicon 预览版已提供 Emby / Jellyfin 接入、媒体墙、搜索、规则推荐、收藏、分类筛选、libmpv 播放、轨道选择、续播和独立双全屏。alpha.10 提供七个经短时解码抽样的社区默认源、IMDb 与豆瓣双评分、分站评分排序及两站 Top 250 榜单筛选。提供版本化 DMG / ZIP、源码与校验值。真实 Jellyfin、Intel 及 Windows 仍需单独验收。

## Windows 交付路径

保留现有 Mac 用户可用版本，先建立 Windows 原生宿主与 libmpv 的最小播放流程。协议数据模型、测试场景和播放行为可复用；UI、渲染、凭据存储与打包需要平台实现。对 Windows UI 技术做小范围验证后再选型，避免提前整体重写。

Windows 首个可下载预览版必须在真实 Windows 设备验证登录、播放、硬件解码、字幕/音轨、退出释放连接、续播、窗口全屏与系统全屏，并提供独立版本包、对应源码、签名状态和 SHA-256；不能用 Mac 测试替代。
