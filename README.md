# muxi

**幕汐 · 播放器与私人影视库**

muxi 是一款免费开源的视频播放器，连接你的 Emby / Jellyfin，将多个媒体源汇成一面海报墙。没有订阅、广告或第三方账号。

[下载 macOS 版](https://github.com/HectorGao/muxi-player/releases) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/HectorGao/muxi-player/issues)

## 功能

- **保存多个媒体源**：首次登录后自动保存，下次打开恢复连接；支持分别浏览或汇总查看。
- **私人海报墙**：继续观看、影片详情、电影与剧集分类，以及未看高分推荐。
- **搜索与收藏**：从全部媒体源搜索，或只搜索某个源；收藏和播放进度同步到影片所属的服务器。
- **排序与筛选**：按入库时间、年份、评分、名称排序；在分类中组合筛选年份、国家 / 地区、类型和观看状态。
- **完整播放控制**：基于 libmpv，支持常见视频格式、片源版本、音轨、内外字幕、倍速、拖动与续播。
- **两种全屏**：铺满当前窗口，或进入 macOS 系统全屏；离开播放时停止取流并保存位置。
- **深浅外观**：原生毛玻璃与动态海报背景，支持跟随系统以及减少动态效果设置。

## 安装

当前提供 **Apple Silicon Mac、macOS 14 及以上**的预览版。

1. 从 [Releases](https://github.com/HectorGao/muxi-player/releases) 下载 `.dmg`。
2. 打开磁盘镜像，将 `muxi.app` 拖入 `Applications`。
3. 弹出磁盘，从“应用程序”启动。更新前先退出旧版。

预览版尚未经过 Apple 公证，首次打开可能出现系统提示。每个版本也提供 APP ZIP、源码和 SHA-256 校验文件。Windows 与 Intel Mac 安装包暂未提供。

## 开始使用

1. 点击“添加媒体源”，选择 Emby 或 Jellyfin，填写地址、账号和密码，可为媒体源起一个名字。地址支持端口和反向代理路径。
2. 点击“保存并连接”。媒体源信息与登录令牌保存在 macOS 钥匙串中，不保存密码；以后打开无需重复填写。更新应用后，系统可能要求重新允许钥匙串访问；服务器令牌过期时可从“管理媒体源”更新登录。
3. 侧栏选择“全部媒体源”汇总浏览，也可以选择单个源。搜索、推荐和收藏会随当前范围切换。一个源离线时，其他源仍可使用。
4. 点击海报查看详情，再播放或续播。剧集先选择季和集；爱心用于收藏。
5. 播放时可切换字幕、音轨、片源版本、分辨率与码率。点击“退出播放”或切换页面，保存进度并停止下载。
6. 在“管理媒体源”中添加、更新登录或移除连接。移除连接不会删除服务器上的影片、收藏或播放记录。

### 常见问题

**高码率影片卡顿**：先选择较低码率的已有片源版本。降低分辨率或码率需要服务器支持转码；本机降低画面尺寸无法减少原始流的下载量。

**分类筛选信息不完整**：年份、国家和类型来自媒体源。首次筛选会读取该分类的元数据，大型媒体库可能需要等待；未标注的信息不会被猜测补齐。

**服务器限制客户端**：Emby 默认采用 SenPlayer 兼容标识，也可按服务商说明选择 Infuse 或 muxi。仍需有效账号及服务器授权；Jellyfin 使用 muxi 标识。
