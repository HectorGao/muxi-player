# muxi

**幕汐 · 播放器与私人影视库**

muxi 是一款免费开源的视频播放器，连接 Emby / Jellyfin、公开影视档案与苹果 CMS 接口，将多个媒体源汇成一面海报墙。无需订阅或第三方账号。

[下载 macOS 版](https://github.com/HectorGao/muxi-player/releases) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/HectorGao/muxi-player/issues)

## 功能

- **保存多个媒体源**。Emby / Jellyfin 登录后自动保存，支持添加苹果 CMS JSON 接口和导入 LibreTV 源列表、TVBox 中的 JSON 采集接口。
- **默认公开片库**。内置 Internet Archive 电影与 Prelinger 纪录影像入口，可分别关闭，也可与私人媒体库一起浏览。
- **私人海报墙**：继续观看、影片详情、电影与剧集分类，以及未看高分推荐。
- **搜索与收藏**。多源并行查询、逐源展示结果，离线源独立提示。私人媒体库同步服务器收藏和进度，在线采集源保存在本机。
- **搜索缓存**。重复关键词先显示本机结果，默认五分钟内复用缓存，之后检查变更。已建立分类索引时直接搜索本机索引。在线源按支持的变更窗口合并更新，定期重新核对已缓存页。
- **有来源的评分**。自动补全可匹配的豆瓣或 IMDb 评分，标明评分网站，缓存七天。缺少外部评分时使用媒体源评分，缺失时显示暂无评分。
- **排序与筛选**：按入库时间、年份、评分、名称排序；组合筛选年代、指定年份、地区、类型、分辨率、HDR、音频和观看状态。本机索引支持增量同步。
- **完整播放控制**：基于 libmpv，支持常见视频格式、片源版本、音轨、内外字幕、倍速、拖动与续播。
- **两种全屏**：铺满当前窗口，或进入 macOS 系统全屏；离开播放时停止取流并保存位置。
- **随时续播**：切回媒体库后，顶部卡片可直接回到刚才的影片，保留位置与片源。
- **自动更新**：从 GitHub 已发布版本检查并下载签名更新，退出时安装；设置中可关闭或手动检查。
- **深浅外观**：原生毛玻璃与动态海报背景，支持跟随系统以及减少动态效果设置。

## 安装

当前提供 **Apple Silicon Mac、macOS 14 及以上**的预览版。

1. 从 [Releases](https://github.com/HectorGao/muxi-player/releases) 下载 `.dmg`。
2. 打开磁盘镜像，将 `muxi.app` 拖入 `Applications`。
3. 弹出磁盘，从“应用程序”启动。更新前先退出旧版。

预览版尚未经过 Apple 公证，首次打开可能出现系统提示。每个版本也提供 APP ZIP、源码和 SHA-256 校验文件。Windows 与 Intel Mac 安装包暂未提供。

## 开始使用

1. 打开即可浏览默认公开源。添加私人媒体库时，进入“管理媒体源”，点击“添加 Emby / Jellyfin”，填写地址、账号和密码，可为媒体源起一个名字。地址支持端口和反向代理路径。
2. 点击“保存并连接”。媒体源信息与登录令牌保存在 macOS 钥匙串中，不保存密码；以后打开无需重复填写。更新应用后，系统可能要求重新允许钥匙串访问；服务器令牌过期时可从“管理媒体源”更新登录。
3. 侧栏选择“全部媒体源”汇总浏览，也可以选择单个源。搜索、推荐和收藏会随当前范围切换。一个源离线时，其他源仍可使用。
4. 点击海报查看详情，再播放或续播。私人剧集先选择季和集，采集接口可选择线路与分集，公开档案可选择实际视频文件。爱心用于收藏。
5. 播放时可切换字幕、音轨、片源版本、分辨率与码率。点击“退出播放”或切换页面，保存进度并停止下载。
6. 在“管理媒体源”中添加、更新登录或移除连接。移除连接不会删除服务器上的影片、收藏或播放记录。
7. 设置中的“软件更新”默认每天检查新版本，包含预览版。首次安装带自动更新功能的版本后，后续即可自动下载更新；普通代码推送不会触发安装。

### 添加采集接口与订阅

在“管理媒体源”的“公开与采集源”中填写名称及 API 地址，例如 `https://example.com/api.php/provide/vod`，点击“添加”。也可以填入源列表 JSON 链接导入订阅。导入会合并新接口，已有源保留。当前导入点播 JSON 接口，脚本和爬虫类型会跳过。

“测活”显示接口响应时间。连接失败后暂缓该源的自动请求，稍后恢复，可随时手动重试。源列表和接口配置保存在钥匙串，重复搜索与收藏保存在本机。

### 评分来源

有豆瓣条目 ID 时尝试读取对应条目的公开评分，暂不可用时回退到 IMDb。IMDb 分数通过 [Agregarr 公共接口](https://agregarr.org/docs/imdb-ratings/)查询，其数据来自 IMDb 数据集。缺少 IMDb ID 时通过 [Cinemeta](https://github.com/Stremio/stremio-addons/blob/master/docs/tutorial/using-cinemeta.md)按片名与年份匹配，歧义条目保持原评分。

详情中的评分链接可以打开原始评分页面。在设置中可关闭外部评分查询。公开片库使用 [Internet Archive 官方 API](https://archive.org/developers/)，文件可用性与条目权限以源站为准。

### 常见问题

**公开片库、评分或更新连接失败时**，检查代理客户端是否将整个 `MuxiPlayer` 进程设为直连。公开片库、评分服务和 GitHub 更新域名可沿用现有代理分流，私人服务器及其播放域名保持直连。

**高码率影片卡顿**：先选择较低码率的已有片源版本。降低分辨率或码率需要服务器支持转码；本机降低画面尺寸无法减少原始流的下载量。

**分类筛选信息不完整**：信息来自媒体源，首次筛选会建立本机索引，大型分类可能需要等待。以后复用缓存并查询增量变更；每天或手动同步时用轻量列表核对删除。服务器未提供的年份、产地和音视频规格归为未标注；如果变更接口不可用，可选择“重建完整索引”。

**服务器限制客户端**：Emby 默认采用 SenPlayer 兼容标识，也可按服务商说明选择 Infuse 或 muxi。仍需有效账号及服务器授权；Jellyfin 使用 muxi 标识。
